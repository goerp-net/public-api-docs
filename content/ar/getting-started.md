واجهة API العامة لدقيق هي واجهة HTTP للشركاء تُصادق عبر **مفاتيح API صادرة عن المستأجر**. استخدمها لمزامنة الطلبات والمنتجات والمخزون والمستودعات والعملاء مع الأنظمة الخارجية.

## عناوين URL الأساسية

| البيئة | عنوان URL |
|--------|-----------|
| الإنتاج | `https://api.daqiqerp.com/api` |
| التطوير | `https://api-dev.goerp.net/api` |
| محلي | `http://localhost:8080/api` |

مسار `/api` جزء من العنوان. كل مسار في هذا التوثيق نسبي لعنوان URL الأساسي. مثلاً `/v1/public/orders` يصبح:

```
https://api.daqiqerp.com/api/v1/public/orders
```

## الحصول على مفتاح API

تُنشأ مفاتيح API من لوحة تحكم دقيق:

**الإعدادات ← مفاتيح API**

يمكن لمدير المستأجر فقط إدارة المفاتيح. شكل المفتاح:

```
daqiq_live_x8s0Ff2kQ1mZ7pR4tYvB9nL6wA3sD5gH8jK2xC0vN1q
```

يُعرض المفتاح كنص **مرة واحدة فقط** عند الإنشاء. احفظه بأمان — إذا فُقد، احذف المفتاح وأنشئاً جديداً.

::callout{type="info"}
قبل التكامل الحقيقي، استدعِ `GET /v1/public/ping` للتحقق من المفتاح والصلاحيات.
::
