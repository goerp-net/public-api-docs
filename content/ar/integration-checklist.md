title: قائمة التكامل
description: أفضل الممارسات لبناء تكامل موثوق مع واجهة API العامة لدقيق.
---

1. **خزّن المفتاح كسر** — متغير بيئة أو مدير أسرار
2. **تحقق عبر `/v1/public/ping`**
3. **اعتمد على `code` وليس `message`**
4. **استخدم `externalOrderId`** وسلسل إعادة المحاولات
5. **عالج 429 بتراجع** — لا حلقة إعادة محاولة ضيقة
6. **تحقق من `availableQuantity`** قبل وعد العميل بالمخزون
7. **لا تتجاوز 10,000 في الترقيم** — استخدم [المشي الزمني](/ar/guides/pagination)
8. **سجّل `traceParent`** عند كل فشل
9. **تقبل قيم enum وحقول جديدة** — قد تُضاف دون تغيير الإصدار

## سياسة التوافق

**التغييرات الإضافية** دون إشعار. **التغييرات الكاسرة** عبر بادئة إصدار جديد. `/v1/public` لن ينكسر تحتك.

## قيود معروفة

| القيد | الحل |
|-------|------|
| رسالة خطأ المصادقة مفتاح i18n خام | استخدم `code` |
| 429 نص عادي وليس JSON | تحقق من الحالة أولاً |
| Idempotency أفضل جهد | لا طلبات متزامنة متطابقة |
| `salesPrice` null في GET منتج واحد | استخدم القائمة + `sku` |
