أرسل مفتاح API في ترويسة **`X-Api-Key`** مع كل طلب:

```bash
curl https://api.daqiqerp.com/api/v1/public/orders \
  -H "X-Api-Key: daqiq_live_x8s0Ff2kQ1mZ7pR4tYvB9nL6wA3sD5gH8jK2xC0vN1q"
```

## ليس Bearer

**لا** تستخدم `Authorization: Bearer` — هذه الترويسة لجلسات المستخدمين ويُتجاهلها في النقاط العامة.

## نطاق المستأجر

المفتاح يُعرّف المستأجر. لا يمكنك تحديد مستأجر في أي طلب. كل قراءة محصورة بمستأجر المفتاح وكل كتابة تُنسب إليه.

## سلسلة أمان منفصلة

`/v1/public/**` تُخدم بسلسلة أمان منفصلة:

- مفتاح API **لا يمكنه** مصادقة نقطة غير عامة
- JWT المستخدم **لا يمكنه** مصادقة نقطة عامة

## تخزين آمن

- متغير بيئة أو مدير أسرار
- **أبداً** في مستودع الكود
- **أبداً** في المتصفح

استخدم [Ping](/ar/api-reference/ping) للتحقق من بيانات الاعتماد.
